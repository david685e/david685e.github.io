# 🛒 Tienda Tech — Proyecto de Pre-Entrega Frontend

## 🎯 Propósito del proyecto
Este sitio web es una tienda virtual demostrativa creada como trabajo de pre-entrega del curso de Desarrollo Frontend. Su objetivo es aplicar los conocimientos adquiridos en **HTML semántico, CSS, diseño responsivo y formularios conectados a servicios externos**.

## ✅ Características implementadas
- **Estructura semántica**: Uso de etiquetas `header`, `nav`, `main`, `section` y `footer`.
- **Navegación interna**: Enlaces ancla para moverse entre secciones del mismo documento.
- **Diseño responsivo**:
  - Sección de Productos con **Flexbox**
  - Sección de Reseñas con **CSS Grid**
  - Media Queries para adaptar a móviles y tablets
- **Estilos**:
  - Fuente personalizada desde Google Fonts
  - Colores, degradados y sombras
  - Efectos de interacción con hover
- **Formulario de contacto**: Conectado a **Formspree** para recibir mensajes por correo electrónico.
- **Contenido multimedia**: Imágenes integradas en la galería de productos.

## 🚀 Tecnologías utilizadas
- HTML5
- CSS3
- Google Fonts
- Formspree (gestión de envío de formulario)
- GitHub Pages (alojamiento gratuito)
